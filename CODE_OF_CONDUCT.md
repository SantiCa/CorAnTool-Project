# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; no harassment, insults or personal attacks; discuss ideas, not people;
credit the work of others (images, data and methods). The maintainer may edit or remove contributions that break
these rules and, in serious or repeated cases, block the person.

Report unacceptable behaviour privately to the maintainer (address in `desktop/package.json`). Reports are kept
confidential.
