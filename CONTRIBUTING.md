# Contributing

Contributions from ichnologists, sedimentologists and developers are welcome. Please follow the
[code of conduct](CODE_OF_CONDUCT.md) and report security problems privately ([SECURITY.md](SECURITY.md)).

## Reporting a problem or proposing a feature
Open an issue describing the bug or the feature. Example images help a lot, but never attach unpublished data.

## Making a change
1. Read [AGENTS.md](AGENTS.md): it contains the working rules for everyone who changes the code — set-up and test
   commands, code rules, how a change is delivered and what documentation to update.
2. Work on a branch and open a pull request. The continuous-integration checks must pass.
3. Describe what changed and why, and how you checked it.

The methods themselves are documented in [docs/TECHNICAL_DOCUMENTATION.md](docs/TECHNICAL_DOCUMENTATION.md); a change
to an algorithm, a default value or a file format must update it.
